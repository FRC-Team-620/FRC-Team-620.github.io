# JMHS FRC 620 Robotics Team

The James Madison High School FRC 620 Robotics team website.

## Dev Setup (Run Once)

### Required Software

* [Install Ruby](https://rubyinstaller.org/downloads/) - Use 3.x

### Install Libraries

Run `bundle install` to install the libraries

## Serve Local

To have the site run on your local machine, run `bundle exec jekyll serve`. Afterwards, access `https://localhost:4000' to access the site. Any changes to code will automatically rebuild and be available.
